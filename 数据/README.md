# 数据

> 本目录放数据实体，不放代码、不放规范。
> 原始资料固定位置：`原始/`。原始区只读：不改名、不转格式、不就地清洗。

---

## 一、目录职责

| 目录 | 放什么 | 谁写 | 规则 |
|---|---|---|---|
| `原始/` | 甲方/现场交付的原始文件 | 提供方 | 只读；保留原文件名、原格式、原单位 |
| `处理后/` | 我方清洗、转换、派生结果 | 本项目程序 | 可重建；不得作为唯一事实来源 |

`处理后/` 目前尚未建立。程序运行产物按既有输出目录存放，**不写回 `原始/`**。

## 三、新增资料

后续再交付时，在 `原始/` 下建 `批次YYYYMMDD/`，批次内保留甲方原文件，并补齐：

| 文件 | 必填内容 |
|---|---|
| `交付说明.md` | 来源、文件清单、覆盖范围、单位、采样频率、环号/里程映射规则、质量存疑说明 |
| `文件清单.csv` | `相对路径,字节,MD5,修改时间` |
| `文件哈希.md5` | MD5 + 相对路径 |

- 已有单个 mdb 保持原位，不搬动。
- 同名重复交付加 `_v2`、`_v3`，不覆盖旧文件。
- 缺失就留空，不放 0 / -1 / 空串占位。
